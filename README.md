# Test GitHub Pages

Minimalna, responsywna strona testowa konta `dchvizja`, napisana w HTML i CSS bez zależności.

Docelowy adres: https://dchvizja.github.io/test_agentow/

GitHub Pages publikuje zawartość głównego katalogu gałęzi `main`.
Aby zmienić stronę, edytuj `index.html` i wyślij commit na `main`.

Lokalny podgląd: otwórz `index.html` w przeglądarce.
